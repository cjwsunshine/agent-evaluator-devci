                文件格式说明（点击展开）
                
支持 JSON（数组）、CSV 与 Excel（.xlsx）三种格式。CSV / Excel 首行为表头，每行一个用例、每列一个参数。文件只需填写用例内容字段；Agent、评测工具、评测阶段、评测指标以上方页面选择为准，由系统统一应用于评测，无需写入文件。

                

                    
                        

                            字段
                            必填
                            说明
                        

                    
                    
                        

                            name
                            必填
                            用例名称，用于在列表中识别该用例。建议简短可读，例如「天气查询-广州-带伞建议」。
                        

                        

                            query
                            必填
                            输入给 Agent 的用户问题或请求文本。多轮对话场景下填首轮 user 输入。
                        

                        

                            expected
                            必填
                            
                                期望输出，将与 Agent 实际输出进行比对评分。具体含义随 metric 变化：
                                
    
                                    
  • contains / not-contains：填一个关键词字符串
    • 
                                    
  • contains-any：填多个关键词，用英文逗号分隔，如 天气,计算
    • 
                                    
  • llm-rubric：填给 LLM 的评分标准描述，如「回答清晰、合理、与问题相关」
    • 
                                    
  • similar：填一段参考答案，会用相似度匹配
    • 
                                    
  • DeepEval / TruLens 类指标：填理想答案文本
    • 
                                

                            		
                        

                        

                            tags
                            可选
                            
                                标签分类，多个标签用英文逗号分隔（如 math,task_completion）。仅作元数据使用，用于在用例列表/报告中按标签筛选与统计，不影响评分。常见组织方式：
                                
    
                                    
  • 业务领域：weather / math / finance / customer_service
    • 
                                    
  • 能力维度：tool_call / reasoning / multi_turn / planning
    • 
                                    
  • 风险/安全：adversarial / safety / jailbreak / pii
    • 
                                    
  • 难度/优先级：p0 / regression / edge_case / smoke
    • 
                                    
  • 语言/来源：zh / en / real_user / synthetic
    • 
                                

                                字段值是自由字符串，不限制具体取值，建议团队内部约定一套统一标签体系。
                            		
                        

                    
                

                
Agent / 评测工具 / 评测阶段 / 评测指标无需写入文件，均以上方页面所选为准，由系统在评测时统一应用。

                
RAGAS 说明：建议 JSON 用例提供 input_payload.contexts 和 expected_payload.reference / expected_payload.ground_truth；CSV / Excel 可使用 context、reference、ground_truth 列。

                
CSV / Excel 示例首行： name,query,expected,tags
